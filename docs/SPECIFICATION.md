# TextMerger 機能仕様・エッジケース仕様書

本書では、`TextMerger` の文字コード決定ルール、ヘッダ行スキップや改行補完のエッジケース挙動、および TUI / CLI の操作仕様を定義します。

---

## 1. 入出力文字コード決定仕様

### 1.1 対応文字コード一覧

| 表示名（入力） | 表示名（出力） | 内部種別 (`EncodingType`) | コードページ / BOM |
| :--- | :--- | :--- | :--- |
| **自動判別 (オリジナル)** *(デフォルト)* | **入力と同じ (オリジナル)** *(デフォルト)* | `Auto` | 入力ファイルごとに自動判別 / 出力は先頭ファイルに追従 |
| `UTF-8 (BOM自動判別)` | `UTF-8 (BOMなし)` | `Utf8NoBom` | CodePage 65001 (BOM 出力なし) |
| *(上記でBOMありも自動認識)* | `UTF-8 (BOMあり)` | `Utf8WithBom` | CodePage 65001 (`EF BB BF` 出力あり) |
| `Shift_JIS (CP932)` | `Shift_JIS (CP932)` | `ShiftJis` | CodePage 932 (Windows-31J) |
| `EUC-JP` | `EUC-JP` | `EucJp` | CodePage 51932 |
| `UTF-16 LE` | `UTF-16 LE` | `Utf16Le` | CodePage 1200 (`FF FE` BOMあり) |
| `UTF-16 BE` | `UTF-16 BE` | `Utf16Be` | CodePage 1201 (`FE FF` BOMあり) |

### 1.2 入出力文字コードの組み合わせマトリクス

| 入力文字コード設定 | 出力文字コード設定 | 入力デコード時の挙動 | 出力エンコード時の挙動 |
| :--- | :--- | :--- | :--- |
| **自動判別 (`Auto`)** | **入力と同じ (`Auto`)** | 各ファイルごとに判別した文字コードでデコード | **結合対象リストの1ファイル目** の判別文字コード（BOM有無含む）で出力 |
| **自動判別 (`Auto`)** | **明示指定 (`X`)** | 各ファイルごとに判別した文字コードでデコード | 指定された文字コード `X` に統一して出力 |
| **明示指定 (`A`)** | **入力と同じ (`Auto`)** | 全ファイルを文字コード `A` としてデコード | 文字コード `A` で出力 |
| **明示指定 (`A`)** | **明示指定 (`B`)** | 全ファイルを文字コード `A` としてデコード | 文字コード `B` に変換して出力 |

> [!NOTE]
> **異なる文字コードのファイルが混在している場合**
> 入力＝`自動判別 (オリジナル)` の場合、1ファイル目が `UTF-8`、2ファイル目が `Shift_JIS`、3ファイル目が `EUC-JP` であっても、それぞれ固有の文字コードで正しくデコードされた上で出力文字コード（出力＝`入力と同じ` なら1ファイル目の `UTF-8`）へ統一して書き出されるため、文字化けは発生しません。

## 2. ヘッダ行スキップ・ファイル結合のエッジケース仕様

### 2.1 ヘッダ行スキップ (`SkipHeaderOnSubsequentFiles`)
- **有効時（デフォルト: ON、スキップ行数: `1`）**:
  - **1つ目のファイル（結合順序の先頭）**: 先頭行（ヘッダ行）を含め、ファイル内のすべての行を出力します。
  - **2つ目以降のファイル**: 各ファイルの先頭から指定された行数（`HeaderLineCount` 行）を読み飛ばし、残りのデータ行のみを出力します。
- **無効時**:
  - すべてのファイルの全行をそのまま順番に出力します。

### 2.2 エッジケースの挙動定義

| ケース | 挙動 |
| :--- | :--- |
| **2ファイル目以降の行数が `HeaderLineCount` 以下の場合** | 全行がヘッダとしてスキップされ、そのファイルからは 0 行出力されます（エラーにはならず次のファイルへ進みます）。 |
| **空ファイル（0 バイト）が含まれる場合** | 何も出力せず正常に通過します。2ファイル目以降がすべて空ファイルまたはヘッダのみの場合でも、1ファイル目の内容はそのまま出力されます。 |
| **ファイル末尾に改行コードがない場合** | 非空ファイルの最終文字が `\n` または `\r` で終わっていない場合、次のファイルと先頭行が1行に連結されてしまうのを防ぐため、**自動的に改行（`WriteLineAsync`）を1つ補完**します。 |
| **改行コード（`\r\n`, `\n`, `\r`）の扱い** | 入力ファイルの改行コード種別（CRLF / LF / CR）をすべて行区切りとして認識します。 |
| **出力先ファイルが入力対象フォルダ内にある場合** | `FileScanner` の一覧取得時、および `TextMergeService` の結合実行時の双方で、出力先ファイルパス（フルパス大文字小文字無視比較）と一致するファイルは**自動的に結合対象から除外**されます（自己参照ループの防止）。 |
| **結合途中でキャンセル・エラーが発生した場合** | 書き込み中の一時ファイル（`.tmp.<GUID>`）は `finally` ブロックで自動削除され、既存の出力先ファイルは変更前の状態が保たれます。 |

## 3. TUI モードの操作仕様・キーボードショートカット

| 操作対象 | キー / マウス操作 | 動作 |
| :--- | :--- | :--- |
| **フォーカス移動** | `Tab` / `Shift + Tab` / カーソルキー | 各入力欄・チェックボックス・リスト・ボタン間のフォーカス移動 |
| **ファイル選択の切替** | ファイル一覧上で `Space` キー または 左クリック | カーソル位置のファイルの結合対象チェック（マーク）を ON / OFF 切替 |
| **結合順序の変更** | `[↑ 上へ]` / `[↓ 下へ]` ボタン | ファイル一覧で現在選択中のファイルの結合順序を前後に移動（1番目のファイルがヘッダ採用元＆出力文字コード基準になります） |
| **複数拡張子フィルタ** | セミコロン `;` またはカンマ `,` 区切り | 例: `*.txt;*.csv;*.tsv`（空欄時は `*.*` として全ファイル対象） |
| **UIテーマ切替** | 上部パネルの「UIテーマ」セレクタ | `Dark`（初期値）/ `Light` / `Default` / `TurboPascal 5` / `Anders` / `Green Phosphor` を即時反映 |
| **結合のキャンセル** | 結合処理中に `[キャンセル]` ボタンを押下 | 結合タスクへキャンセル要求を送り、安全に中断 |
| **アプリケーション終了** | `[終了]` ボタン または `Ctrl + Q` (`Esc`) | 実行中のタスクがあればキャンセルして終了 |

## 4. CLI（ヘッドレス）モード仕様

バッチ処理やスクリプトからの自動実行向けに、`--cli` オプションによるヘッドレス実行をサポートしています。

### 4.1 書式
```bash
dotnet run --project TextMerger -- --cli <入力フォルダ> <出力ファイル> [検索パターン] [ヘッダスキップ行数]
```

### 4.2 引数一覧

| 位置 | 引数名 | 必須 | デフォルト値 | 説明 |
| :---: | :--- | :---: | :--- | :--- |
| 第1引数 | `--cli` | 必須 | - | CLI モードで起動するためのフラグ |
| 第2引数 | `<入力フォルダ>` | 必須 | - | 結合元ファイルを検索するディレクトリパス |
| 第3引数 | `<出力ファイル>` | 必須 | - | 結合結果の出力先ファイルパス |
| 第4引数 | `[検索パターン]` | 任意 | `"*.txt;*.csv"` | セミコロンまたはカンマ区切りのワイルドカード |
| 第5引数 | `[ヘッダスキップ行数]` | 任意 | `1` | 2ファイル目以降でスキップする先頭行数（`0` を指定するとスキップなし） |

### 4.3 終了コード (Exit Code)
- `0`: 結合処理が正常に完了
- `1`: 引数不足、または指定条件に一致する対象ファイルが 0 件の場合（標準エラー出力にメッセージを出力）
